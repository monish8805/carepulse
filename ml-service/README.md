# ml-service — sepsis early-warning model

The serving layer from `sepsis_ml_master` (PhysioNet/CinC 2019, research
prototype — **not a diagnostic tool, not clinically validated**), run as its
own process. The CarePulse backend is the only caller; browsers never reach it.

Copied from `sepsis_ml_master`: `sepsis_core.py` (generated by the notebook —
don't edit by hand), `sepsis_router.py`, `api.py`, the six models listed in
`artifacts/model_registry.json`, `artifacts/`, `results/model_comparison.csv`
(for `GET /comparison`) and `sample_patients.json` (six held-out ICU stays,
replayed into CarePulse by `backend/scripts/replayVitals.ts`). The notebook,
Streamlit app, figures and training outputs stay in the original folder.

One CarePulse change: `POST /predict` also returns `model` and `model_version`,
which the backend stores on every prediction.

## Run

```bash
uv venv --python 3.11 .venv            # the models were trained on Python 3.11
uv pip install --python .venv/bin/python -r requirements.txt
./start.sh                             # http://127.0.0.1:8000, docs at /docs
```

## Check

```bash
curl http://127.0.0.1:8000/health
curl -X POST http://127.0.0.1:8000/predict -H "Content-Type: application/json" \
  -d '{"history":[{"hour":10,"HR":92,"O2Sat":96,"Temp":37.4,"SBP":115,"MAP":80,"DBP":65,"Resp":20}]}'
```

## What the backend must send

- **The whole history so far**, not just the last 6 hours. Only the latest 6
  go into the network, but older hours decide what a gap is filled with.
- **`hour` = whole hours since the first reading**, one row per hour. A
  duplicate hour is a 422; a missing hour is treated as unmeasured.
- Vitals exactly as recorded, `null` when not measured — the model does its
  own forward-fill and median imputation.
- No names, emails or ids.

Of the six sample patients, only `p012210` (septic, label onset hour 37)
reaches HIGH with the primary model — first at hour 3.
